## Sobre o Python

A linguagem Python foi criada pelo holandês **Guido van Rossum** no instituto de pesquisa **Centrum Wiskunde & Informatica (CWI)**, localizado em Amsterdã.

- **Início:** Final dos anos 80, com a implementação iniciada em dezembro de 1989  
- **Objetivo:** Criada como um projeto pessoal durante o Natal, sendo sucessora da linguagem ABC  
- **Lançamento:** A primeira versão oficial foi publicada em 1991  

Fonte: https://pt.wikipedia.org/wiki/Python
